Multi-modal VLA for Manipulation

시각-언어-행동을 통합하여 복잡한 로봇 조작 과업을 수행하는 기초 모델 연구

Project Overview

이 프로젝트는 시각(Vision), 언어(Language), 행동(Action) 데이터를 대규모로 학습하여 로봇이 다양한 환경에서 범용적으로 동작할 수 있도록 하는 VLA 모델을 개발하는 것을 목표로 합니다.

Key Features

  • Cross-modal Attention Mechanism
  • Large-scale Robot Interaction Dataset
  • Zero-shot Generalization
