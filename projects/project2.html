Pseudo-Tactile Feedback Generation

기존 비디오 데이터셋에서 가상의 촉각 신호를 예측하여 학습 데이터를 확장하는 기술

Project Overview

비전 기반의 로봇 학습은 시각 정보에만 의존하지만, 실제 조작에서는 촉각 정보가 매우 중요합니다. 본 연구는 Video-to-Tactile 변환 모델을 통해 대규모 비디오 데이터셋에 가상 촉각 라벨을 생성합니다.

Key Features

  • V2T (Vision to Tactile) Generative Model
  • Physics-informed Consistency Loss
  • Tactile-aware Manipulation Policy
